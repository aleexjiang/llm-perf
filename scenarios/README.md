# scenarios/ — 多轮对话剧本

三个多轮场景的用户台词，从已退役的「单发版工具包」迁入。
llm-perf 目前的 multiturn 是**合成轮次**（`system_tokens` / `turn_tokens` 填充），
后续若要做**真实剧本驱动**的多轮测试，从这里接入。

## 剧本设计四原则（改写时遵守）

1. **剧情弧线**：开场 → 深入 → 转向 → 收敛，不是孤立问答堆砌
2. **跨轮强依赖**："你上面提到的…""把刚才那份…"——服务端没带全 history 会当场露馅
3. **鲁棒指代**：只做位置指代，**不引用回复里的具体数字/措辞**（模型回复有随机性）
4. **指令类型多样**：问答 / 改写 / 扩写 / 压缩 / 核对 / 汇总，回复长度有变化，增长曲线才真实
